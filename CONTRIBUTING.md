# Contributing to linux-navicat

First off, thank you for considering contributing to `linux-navicat`! It's people like you that make `linux-navicat` such a great tool for the community.

## 🚀 How Can I Contribute?

### 1. Reporting Bugs
Before creating bug reports, please check the issue list as you might find out that you don't need to create one. When creating a bug report, please include as many details as possible:
- **Use a clear and descriptive title.**
- **Describe the exact steps to reproduce the problem.**
- **Provide screenshots or error logs if applicable.**
- **Specify your environment** (OS, JDK version, MySQL version).

### 2. Suggesting Enhancements
Feature requests are tracked as GitHub Issues. When proposing a new feature:
- Use a clear and descriptive title.
- Provide a step-by-step description of the suggested enhancement.
- Explain why this feature would be useful to most users.

### 3. Submitting Pull Requests (PR)

1. **Fork the Repository**: Create your own fork of `linux-navicat`.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   # or for bug fixes:
   git checkout -b fix/issue-description
   ```
3. **Make your changes**: Follow the project's coding standards.
4. **Build & Test locally**:
   ```bash
   mvn clean package
   ```
   Ensure the project compiles without errors.
5. **Commit your changes**: Write clear, concise commit messages.
   ```bash
   git commit -m "feat: add CSV export feature for query results"
   ```
6. **Push to your fork**:
   ```bash
   git push origin feature/amazing-feature
   ```
7. **Open a Pull Request**: Submit the PR to the `main` branch of `linux-navicat` and describe your changes.
